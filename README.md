# English Study Helper（セコいVer. たぶんSafari専用）

iPhone の Safari で使う英語学習ページ。サーバーは使わず、データは端末の中（localStorage）にだけ保存します。外部の AI や API は使わず、iPhone に元からある機能だけで動きます。

## できること

| 機能 | 使う iPhone の機能 |
|---|---|
| 英文を貼り付けて入力 | — |
| 写真・カメラから英文を取り込む（任意） | テキスト認識表示（Live Text） |
| 英文を一文ずつに分ける | ページ内の JavaScript |
| 一文ずつ読み上げ | 読み上げ音声（`speechSynthesis`） |
| 和訳 | Safari の「ページを翻訳」 |
| 発音チェック | 音声認識（`webkitSpeechRecognition`、Siri の音声入力と同じエンジン） |

## 使い方（iPhone）

1. **英文を入れる**
   - 基本：英文をコピーして入力欄に貼り付ける（記事・メール・PDF など何でもよい）
   - カメラ：入力欄をタップ → もう一度タップ →「テキストをスキャン」
   - 写真：「写真を表示」で写真を選ぶ → 写真の文字を長押しして選択 → コピーして入力欄に貼り付ける
2. **「一文ずつに分ける」** を押す
   - 英文は2万文字まで、文の数は1,000個まで。400文字を超える文は、カンマなどの区切りで自動的に分ける
3. **和訳（任意）**：② の「翻訳ページを開く」を押す → アドレスバーの「ぁあ」→「日本語に翻訳」→ 日本語になったら「← Back」で戻ると、訳が各文の欄に入っている
   - 翻訳ページは英文だけのページになっている（日本語が混じると Safari が翻訳メニューを出さないため）
   - 設定の「翻訳エリアの並べ方」で、段落ごと（文脈重視）と一文ずつ（対応が確実）を切り替えられる
4. 各文の **▶ 聞く** で読み上げる（訳の下の ▶ 聞く で日本語訳も読み上げられる）。**🎤 話す** で発音をチェックする
   - 話し終えて少し黙ると自動で判定する（初期値は5秒。設定で3秒・8秒・「■ を押すまで待つ」に変えられる）。文の最後まで正しく言えたときはすぐ判定する
   - 緑＝一致、赤＝抜け・違い、取り消し線＝余分に言った語
   - I've と I have、3 と three、can't と cannot などの違いは同じとみなす
   - 🎤 が使えない環境では、🎤 を押すと入力欄が出るので、キーボードの音声入力で話して「判定」

5. **操作パネル**（画面の下）：音楽プレイヤーのように、「今の文」（青い枠の文）を読んだり、前後へ動いたりする
   - 右寄せのときの並びは、左から「🔖 次のしおり／⚙️ 設定」「▶ 全部読む」「⏮ 前へ」「⏭ 次へ」「▶ 英語／▶ 日本語」（左寄せのときは左右が逆になる）
   - 今の文は、⏮ ⏭ やカードのボタンを押したとき、手でスクロールして止めたとき（画面の真ん中の文）に変わる。読み上げ中はスクロールしても変わらない
   - ▶ 全部読む：今の文から最後まで、1文ごとに英語→日本語→英語の順で読む。それぞれ何回読むかは ⚙️ 設定で選べる（訳がない文の日本語は飛ばす）。読んでいる途中で ⏮ ⏭ を押すと、その文から読み直す

6. **しおり**：各文の番号の横の 🔖 を押すと、その文に印がつく（もう一度押すと外れる）。印は何個でもつけられ、操作パネルの 🔖 を押すたびに次の印の文へ移動する（最後の次は最初の印に戻る）

7. **文章の保存と切り替え**：画面のいちばん上の「📄 文章の名前」を押すと、保存してある文章の一覧が出る
   - 「＋ 新しい文章」で、今の文章を残したまま別の英文を入れられる
   - 一覧の文章を押すと切り替わり、最後に見ていた文から再開する。✎ で名前を変え、🗑 で消せる（名前をつけていない文章は、英文の書き出しが名前になる）
   - 設定（声・速さ・左右など）はすべての文章で共通

8. **左右設定**：「左」「右」で、操作ボタンを片手で押しやすい側（画面の端から約2/3の範囲）に寄せる。選んだ側は次に開いたときも同じになる

## 注意

- ホーム画面に追加して使うより、Safari のまま使うのがおすすめ（翻訳メニューは Safari にしかないため）
- マイクの許可を求められたら「許可」を選ぶ。拒否してしまったら「設定」アプリ → Safari → マイク で変更する

### データの扱い

このアプリ自体はクライアント完結型です。自前のサーバーはなく、英文・訳・スコアは端末のブラウザ（localStorage）にだけ保存され、アプリから外へ送ることはありません。

ただし、使っているブラウザの機能の中には、その提供元（Apple や Microsoft など）のサーバーで処理されるものがあります。

| 機能 | iPhone の Safari | Windows の Edge |
|---|---|---|
| 読み上げ（🔊） | iPhone の中 | PC の中（名前に「Online」と付く声は Microsoft のサーバー） |
| テキスト認識表示（Live Text） | iPhone の中 | — |
| 発音チェック（🎤） | 機種や設定によっては、音声が Apple のサーバーに送られる | 音声が Microsoft のサーバーに送られる |
| ページ翻訳 | 英文が Apple のサーバーに送られることがある | 英文が Microsoft のサーバーに送られる |

どれもブラウザの機能による通信で、このアプリが独自に送っているものではありません。完全にオフラインではないので、人に見せたくない文を扱うときは気をつけてください。

## 開発

```sh
node tests/test.js             # 文の分割と発音比較のテスト
python3 -m http.server 8765    # http://localhost:8765/ で確認
```

JS や CSS を変えたら、`index.html` と `translate.html` の `?v=` の数字を上げる。GitHub Pages はファイルを最大10分ブラウザに保存させるので、上げないと古いファイルが使われることがある。
